# images

`hero.svg` is a placeholder. Replace it with a real photo:

1. Drop the file in here (e.g. `hero.jpg`, ~1600×900 or larger, subject standing
   in the right third of the frame).
2. Update the `<img src>` in `src/components/Hero.astro`.

The hero already sits under an 80%-opacity black scrim, so a bright,
high-contrast photo works better than a dark one.
